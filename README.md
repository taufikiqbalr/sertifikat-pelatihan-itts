# Sertifikat Pelatihan ITTS

Aplikasi penerbitan dan validasi sertifikat untuk webinar, pelatihan, workshop, dan kegiatan ITTS.

Fitur utama:
- Admin login
- Master kegiatan dan template sertifikat per kegiatan
- Upload gambar template sertifikat atau gunakan template default
- Editor posisi teks dan QR code
- Penerbitan sertifikat peserta secara satuan/batch
- Nomor sertifikat otomatis atau manual
- QR code menuju halaman validasi publik
- Status sertifikat valid/revoked
- Unduh sertifikat PNG/PDF
- Siap dideploy di Vercel

Dokumentasi instalasi lengkap akan ditambahkan bersama source code.
